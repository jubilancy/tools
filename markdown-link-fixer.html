Markdown Link Fixer

Cleans up broken multi-line markdown links for Obsidian — handles nested image-in-link exports, Google Lens copy-paste dumps, empty alt text, and dangling standalone images.

Tip: Ctrl/Cmd + Enter runs the fixer from the input box. Uncheck "drop image markup" if you want to keep favicon/thumbnail images alongside the cleaned link.
