Build a multi-color gingham/plaid pattern, tweak hex values live, pick your size, export PNG or SVG.

Tip: each color gets its own horizontal + vertical stripe. Same-color crossings get an automatic darker "self-overlap" shade; different-color crossings blend the two. Edit any hex value directly or use the color swatch, then hit regenerate to redraw the preview before exporting.
